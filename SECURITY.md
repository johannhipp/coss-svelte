# Security Policy

## Supported Versions

`coss-svelte` is not published to npm yet. Until the first public release, security fixes land on the default branch only.

After the first npm release, supported versions will be listed here.

## Reporting a Vulnerability

When this repository is public, report vulnerabilities through GitHub Security Advisories if available. If advisories are not enabled yet, open a minimal issue that says a private security report is needed and do not include exploit details.

Please include:

- Affected package or app.
- Impact and reproduction steps.
- Any known workaround.
- Whether the issue is already public.

Maintainers will acknowledge valid reports and coordinate a fix before publishing details.
