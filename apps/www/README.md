# apps/www

This app will be the SvelteKit + Vite documentation site for coss-svelte.

It should mirror the role of `cosscom/coss` `apps/www`, while using SvelteKit routes and Svelte-native examples. The target visual direction is the COSS UI docs experience at `https://coss.com/ui/docs`: clean navigation, readable component docs, examples, and copy-and-own installation guidance.

Implementation has not started. Keep this folder free of component demos until the registry and first component batch exist.
