# packages/coss-svelte/src

Source files for the publishable `coss-svelte` package.

## Structure

- `components` - exported Svelte component primitives and component parts.
- `internal` - package-local helpers that are not public exports.
- `index.js` - public JavaScript entry point.
- `index.d.ts` - public type declarations.
- `metadata.js` - component status and registry metadata.
- `utils.js` - shared public utilities.

Keep public exports, type declarations, registry metadata, and docs examples aligned when changing components.
